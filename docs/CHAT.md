# 聊天与 Cloudflare R2 配置

已接入大厅、俱乐部、牌桌聊天。聊天与成员数据保存在四川 MySQL，通过现有 WSS 收发；图片、语音和视频文件保存到 Cloudflare R2。未配置 R2 时文字聊天可用，发送媒体会提示“媒体存储尚未配置”。

## 入口与范围

当前版本暂时隐藏俱乐部入口，底部只显示大厅、聊天、我的；俱乐部代码和服务端数据保留，以下俱乐部说明供后续恢复使用。

- 底部“聊天”直接进入大厅聊天页：按应用语言进入大厅频道，支持文字、Emoji、图片、语音和短视频，与俱乐部／牌桌使用同一套输入组件。
- 底部“俱乐部”：只显示自己的俱乐部，无搜索或公开目录。未加入时可创建或输入邀请码；同一时间只能加入一个，最多 200 人。会长可编辑简介／公告、移除成员、转让会长、禁言，并创建 7 天有效的邀请码。最后一位会长退出时关闭俱乐部。
- 俱乐部详情：进入成员聊天，支持文字、图片、语音、短视频。加入后可读取该俱乐部历史；退出或被踢后停止访问。
- 牌桌上方 `forum` 图标：完整聊天。原快捷短语保留。观战者只读，坐下后发言；使用房间实例的随机频道 ID，避免房间号重复造成串聊。房间关闭时关闭频道。
- 首版未增加好友私聊、系统通知中心、收益、排行榜或俱乐部比赛；这些仍属于 `Durak_Club_MVP_Design.md` 的后续阶段。会长账号目前仍使用现有游客身份，正式运营前需补可恢复账号绑定。

## 消息与媒体

文字最多 500 Unicode 码点；历史每页 50 条，断线后按消息 ID 补齐。发送失败可重试，同一频道、发送者、客户端 nonce 的重试不会重复入库。长按消息支持删除、举报、屏蔽；会长／指定平台管理员可删除其他人的消息并禁言。

| 媒体 | 限制 | 校验 |
|---|---|---|
| 图片 | JPEG/PNG/WebP，5 MiB | 实际解码检查，最多 2000 万像素，生成缩略图 |
| 语音 | AAC 的 M4A，2 MiB、60 秒 | FFprobe 验证音轨、时长；点击录音，可暂停、删除和发送 |
| 视频 | MP4/MOV，20 MiB、60 秒 | FFprobe 验证 H.264/HEVC、尺寸和时长，生成封面；播放兼容性取决于设备解码能力 |

公共聊天页为 `ChatScreen`，公共输入栏为 `ChatComposer`；大厅、俱乐部、牌桌复用，服务端返回媒体／发言权限。输入栏不使用“＋”或左侧图片按钮：圆角输入框内有表情，空文字时右侧显示相机与绿色录音按钮，有文字时切换为发送。相册、照片和视频选择统一从相机入口进入；手机相机页左下角可打开相册，照片／视频标签控制拍摄及选择类型，桌面／Web 使用同一相机入口的菜单。观战者仅可阅读。

表情使用 [`emoji_picker_flutter`](https://pub.dev/packages/emoji_picker_flutter) 4.5.4（MIT），公共面板为 `ChatEmojiPickerSheet`，支持分类、最近使用、搜索和长按选择／记住肤色。统一使用中英文关键词集，避免切换应用语言后受组件搜索缓存影响；蒙古语界面的搜索提示说明使用英文，也可搜索中文关键词。选中表情后回到输入框，在原光标处插入或替换原选中文字，保留完整的肤色／组合序列并按服务端的 500 Unicode 码点限制校验；不会自动发送。表情按 Unicode 文字收发，使用设备字体显示，不增加 R2 对象或额外图形资源包。

点录音后显示实际音量波形和时长，可暂停、继续、删除、发送；录满 60 秒自动结束为可试听的草稿，不自动上传。切后台、离开页面或失去发言权限时释放并丢弃未发送录音；牌桌实时麦克风／摄像头正在发布时，先关闭它们再录制消息。相册选择或拍摄后先预览，再明确点击发送才上传；Android/iOS 拍摄页支持照片／视频切换、前后镜头、设备支持的闪光灯与缩放，录像最长约 59 秒，为编码时长留余量。实际拍照、录音和视频播放需使用真机验证。Web 暂不开放语音录制。

每位用户每天最多预留 100 次上传、200 MiB，上传授权有效 5 分钟；短期发送和上传也有限频。媒体完成前校验服务器读取一次文件，不长期保存副本。校验后在 R2 内按 ETag 条件复制到另一个 UUID，避免重复使用上传链接覆盖已发送文件。

R2 对象路径统一为：
```text
chat/20261014/{UUID}.jpg
chat/20261014/{UUID}.m4a
chat/20261014/{UUID}.mp4
chat/20261014/{UUID}_thumb.jpg
```
日期由服务器按 UTC 生成。频道、发送者和成员权限保存在数据库中，不再分目录。原文件、缩略图和封面都在 `chat/` 下。应用权限有效期从上传授权创建时刻计算 7 天，到期不再签发读取地址，显示“文件已过期”；R2 按对象年龄清理，物理删除不是精确到秒。读取链接有效不超过 60 秒，已签发的链接在这段时间内可能仍可使用。客户端不持久化下载媒体，语音临时录音在发送后删除。

## 大厅界面与邀请

底部固定三页：大厅、聊天、我的；俱乐部暂时隐藏；使用统一标题、配色、卡片与按钮。大厅为“全部 + 四种游戏”筛选，列表卡片只显示头像和名字，游戏名称在卡片外；底部为创建房间／输入房间号。切页保留列表位置、筛选与大厅聊天，文字草稿和聊天位置保存在当前登录会话内，应用重启后不保留。切页停止并丢弃录音，不显示聊天未读提示。

创建房间时先选游戏、人数、公开／仅邀请，再点击“创建并进入”。四种游戏均支持明确选择可见性；好友玩法不引入自动匹配。仅邀请房间由服务器排除在大厅列表之外，仍可通过房间号进入并默认观战。旧客户端未传 `locked` 时，Muushig 保持原默认值，其他三种游戏默认仅邀请。金币、每日任务、回放、排行榜与设置在“我的”内。Flutter 默认服务器为 `wss://kzur.sdg8888.com/ws`，设置中保存的地址及显式构建参数仍可覆盖。

俱乐部邀请接口：会长调用 `club_invite_create(id)` 得到 128 位随机邀请码（32 位十六进制）与 `expires_at`。会长复制后自行分享，接收者在俱乐部页输入，先调用 `club_invite_info(token)` 查看名称、邀请人和有效期，明确确认后调用 `club_join(token)`。邀请码在会长失去会长身份、俱乐部关闭或满 7 天后失效；服务器拒绝按裸 `id` 加入，并限制创建／验证频率。`club_list` 仅返回本人俱乐部，非成员不能通过 `club_info` 获取成员列表。数据库启动时自动创建 `chat_club_invites` 表，无需手工建表。

## 必需的 R2 参数

| 参数 | 获取位置／用途 |
|---|---|
| `R2_ACCOUNT_ID` | Cloudflare 账户 ID，32 位十六进制；不是邮箱或域名 |
| `R2_BUCKET` | 已创建的 R2 存储桶名称，当前为 `khuzur` |
| `R2_ACCESS_KEY_ID` | 创建 R2 S3 API 凭证后得到的 Access Key ID |
| `R2_SECRET_ACCESS_KEY` | 同一组凭证的 Secret Access Key，创建时保存 |

创建 R2 API 凭证时选择对象读写权限，并限定到该存储桶。不是 Cloudflare Global API Key，也不是 Agora 凭证。上传地址由四川服务器签发，手机直接使用 R2 的 HTTPS 接口，不需要前端密钥或公开文件域名。

服务器文件：`/opt/khuzur/server/.env`，Agora、R2 和聊天管理员配置统一放在这里。模板为 `server/.env.example`；实际 `.env` 已被 Git 忽略，模板可以提交。只在服务器填密钥，不发到聊天、不写入 Dart、不提交 Git。数据库连接仍配置在 `etc/config`。

启动脚本优先只读取 `.env`；没有 `.env` 时才兼容旧 `.env.chat`、`.env.rtc`。迁移旧服务器时先合并两个旧文件中的已填值，再启用 `.env`，不要用空模板覆盖凭证。`.env` 按 shell 语法读取，含空格或特殊字符的值需用引号包裹。

```sh
cd /opt/khuzur/server
# 没有配置文件时复制模板；已有文件请直接编辑，避免覆盖。
[ -f .env ] || cp .env.example .env
nano .env
chown khuzur:khuzur .env
chmod 600 .env
systemctl restart khuzur
```

存储桶保持私有，关闭 `r2.dev` 公共访问，不通过公开自定义域名分发聊天文件。控制台在存储桶 Settings → Object Lifecycle Rules 添加：前缀 `chat/`、7 天删除。头像若日后上传，应使用 `avatars/`、`club-icons/` 等其他前缀。

如果用于 Flutter Web，还需在 R2 CORS 配置实际 Web 来源，允许 `PUT/GET/HEAD` 和 `Content-Type`。APK 没有浏览器 CORS 限制。

也可通过维护脚本添加规则（保留其他规则；需要具备生命周期管理权限的凭证）：
```sh
cd /opt/khuzur/server
set -a
. ./.env
set +a
python3 media/r2_server.py --configure-lifecycle
```

参考：[R2 临时授权 URL](https://developers.cloudflare.com/r2/api/s3/presigned-urls/)、[生命周期](https://developers.cloudflare.com/r2/buckets/object-lifecycles/)、[S3 API 兼容性](https://developers.cloudflare.com/r2/api/s3/api/)。

## 服务与运维

继续使用 Lua/Skynet，不需要更换 Go。`service/chat.lua` 处理频道与成员权限；`lualib/chat_store.lua` 由既有数据库队列调用。首次启动自动创建聊天数据表；MySQL 不可用时聊天失败关闭，不回退到易丢消息的内存存储。MySQL 连接和表均使用 `utf8mb4` 支持 Emoji。

`run.sh` 同时启动仅监听 `127.0.0.1:9761` 的 Python R2 签名／媒体校验辅助进程。内部密钥每次启动生成；无需开放 9761，无需 Nginx 上传路径，无需 Docker。辅助进程日志由 `journalctl -u khuzur -f` 查看，不输出存储密钥或完整授权 URL。

```sh
apt-get update
apt-get install -y ffmpeg python3-pil
# 可选平台审核员，填已存在的用户 ID，不接受客户端自报角色。
# .env: CHAT_ADMIN_UIDS=123,456
```

平台举报列表／处理接口为 `chat_reports`、`chat_report_resolve`，需服务端 `CHAT_ADMIN_UIDS` 授权。举报持久化；本版暂没有独立 Web 管理后台。
