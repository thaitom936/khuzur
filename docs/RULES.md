# Muushig（Муушиг）游戏规则

## 基本设定

- 人数：2～5 人（标准 5 人）
- 牌组：32 张（每花色 7、8、9、10、J、Q、K、A），A 最大、7 最小
- 目标：每人从 **15 分**开始，先减到 **0 分（或以下）** 者获胜

## 一局流程

### ① 发牌

- 每人 5 张，翻开 1 张定**主花色**（这张就是"明牌"），其余扣着做底牌
- 5 人局底牌正好 6 张；庄家每局顺时针轮换

### ② 叫牌（参与/不参与）

- 从庄家下家起，每人选择"打"或"弃"
- 弃的人本局旁观：头像和名字置暗，分数不变
- 限制：分数 ≤1 的人必须打；至少要有 2 人参与（前面都弃了，最后的人被强制打）

### ③ 换底牌

- 从庄家下家起按顺序，参与者可弃掉手里若干张、从底牌补相同张数
  （最多 5 张，受剩余底牌限制），也可以不换
- **庄家特权**：轮到庄家换牌时，可用手里任意一张牌换走翻开的明牌
  （每局一次）。主花色仍以最初翻开的为准，不因此改变

### ④ 出牌（共 5 墩）

- 庄家下家（第一个参与者）先出，之后每墩由上一墩赢家先出
- 跟牌规则（按优先级）：
  1. 有领出花色 → **必须跟同花色**（不要求压过）
  2. 没有 → **必须出主牌**（不要求盖过已出的主牌）
  3. 也没有 → 随意垫牌
- 一墩里：有主牌则最大的主牌赢；没有则领出花色里最大的赢
- 界面：中央的牌从小到大排列（不显示出牌人）；一墩结束所有牌飞向赢家，
  赢家头像上以小牌堆累计墩数

### ⑤ 结算

- 参与者：赢几墩扣几分
- 弃牌者：分数不变
- 参与但 0 墩：罚 +5 分 ⚠️ *此条为传统规则默认值，待确认——没有它"弃牌"永远不划算*
- 有人 ≤0 分 → 整场结束，分数最低者胜（并列同胜）；否则庄家移给下家开下一局

## 超时与托管（联机）

- 叫牌 10 秒，换牌/庄家换明牌 15 秒，出牌 15 秒
- 超时由 AI 代打；连续超时 2 次进入托管（可手动取消）；断线由 AI 代打，重连回桌

## 可配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| `startScore` | 15 | 初始分 |
| `noTrickPenalty` | 5 | 参与 0 墩罚分（待确认） |
| `decidePhase` | 开 | 是否有叫牌阶段 |
| `exchangePhase` | 开 | 是否有换底阶段 |
| `dealerTakesTrump` | 开 | 庄家换明牌特权 |
| `mustFollowSuit` / `mustTrump` | 开 | 跟花色 / 缺门必出主 |
| `mustBeat` / `mustOvertrump` | 关 | 不要求压过 / 不要求盖主 |
| `mustPlayAtScore` | 1 | 分数 ≤此值必须打 |
| `minPlayers` | 2 | 每局最少参与人数 |
| `maxExchange` | 5 | 单人最多换几张 |

规则由 `testdata/rules/` 的共享用例锁定，Dart / Lua 两个引擎跑同一份用例保证一致。
